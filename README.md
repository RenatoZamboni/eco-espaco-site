# Site do Eco Espaço & Lazer

Site estático de uma página. Publicado com GitHub Pages a partir da pasta raiz deste repositório.

- `index.html`: a página inteira (textos, estilo e funcionamento).
- `img/`: fotos reais tratadas, com versão leve (`-640`) para celular.
- `robots.txt`: permite que o Google leia o site.

Para atualizar, edite `index.html` e envie para a branch `main`. O site atualiza sozinho em alguns minutos.
